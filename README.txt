JASWINDER ARTIST WEBSITE
========================

FILES
- index.html        Home page
- mehndi.html       Mehndi Design page
- makeup.html       Makeup page
- contact.html      Contact page
- registration.html Appointment request form
- styles.css        Shared responsive styling
- script.js         Mobile navigation and demo form message

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Click the navigation links to move between pages.

BEFORE PUBLISHING
- Replace sample contact information in contact.html with your real business details.
- The registration form is a visual/demo form only. It does NOT send, save, or email bookings.
  Connect a form service or backend before collecting customer information.
- Photos are loaded from external image URLs, so an internet connection is needed for those images.
- You can publish this static website using Netlify, GitHub Pages, or another static hosting provider.
